# Retail Sales Analysis and Visualization Using Python & Seaborn

## Project Overview
This project analyzes retail sales data using Python, Pandas, Matplotlib, and Seaborn. It explores sales performance, profitability, regional trends, product categories, and discount impact.

## Dataset
- Dataset: Sample Superstore
- Total Records: 9,994
- Total Columns: 21
- Missing Values: 0
- Duplicate Records: 0

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis
1. Overall business performance
2. Sales by product category
3. Monthly sales trends
4. Profit by region
5. Sales by product sub-category
6. Relationship between discount and profit

## Key Business Insights
- Technology generated the highest sales among the three categories.
- The West region generated the highest profit.
- November recorded the highest monthly sales.
- Chairs and Phones were strong-performing sub-categories.
- Higher discounts were generally associated with lower profitability.

## Project Structure
- `data/` – Dataset
- `charts/` – Saved visualizations
- `retail_analysis.py` – Python analysis code
- `requirements.txt` – Project dependencies

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python retail_analysis.py`.

## Conclusion
This project demonstrates how data analysis and visualization can transform raw retail data into useful business insights and support data-driven decision-making.
